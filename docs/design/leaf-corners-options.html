FE-113 Leaf corners: text fields, attached panels and the rest

Buttons, Add to Cart, the qty stepper and the Sign In button are already leafed and stay the same in every variant. Each variant changes text fields, textareas, open select and search panels, checkboxes, icon buttons (gallery arrow, view switch, delete), family swatches and filter colour tiles. The password field shows the focus ring. On a real phone the sort and Business Type selects open as a bottom sheet, which does not change; the phone frame shows the list as a drop-down only to compare the corners. If you want a mix, answer like "fields from 2, panels from 3".

1. Fields stay square

Only things you press get the leaf (icon buttons, view switch); text fields, textareas, checkboxes, swatches and colour tiles stay square, and panels stay square with a small gap, as now.

2. Quiet leaf on fields

Text fields and textareas get the small leaf (10px) so they read lighter than the 16px buttons and selects; panels float with a gap as their own small leaf; family swatches get the small leaf, colour tiles stay square.

3. One shape everywhere

Text fields get the same 16px leaf as buttons; an open select or search drops its bottom-left curve and the panel joins it with no gap, so field and list are one leaf; checkboxes, swatches and colour tiles get a small leaf too (checkbox needs a new 4px token).
