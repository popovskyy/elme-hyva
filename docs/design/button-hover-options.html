FE-112 Button hover: calmer and smoother

Row 0 is the hover on the site today. Rows 1-5 are the calmer looks: slower in (450-550 ms), a little quicker out so the button never feels sticky. Hover the buttons in the desktop frame (or Tab to them: keyboard focus gets the same look), or press Replay. Slow motion x4 is there to judge the curve. Phones have no hover, so the phone frame shows the press only, and it is the same in every look. Outline and link buttons have no fill, so they only fade in every look. Button colours, the click ripple and the Add to Cart success motion do not change.

0. Now

The hover on the site today: the colours snap over and a narrow sheen flashes across, then sweeps back when the pointer leaves.

Colours 150 ms, cubic-bezier(.4, 0, .2, 1). Sheen 300 ms, ease-out-quint.

Desktop 1280: hover a button

Phone 390 today: tap a button and the hover colours stay until you tap somewhere else

1. Slow crossfade

Colours only: charcoal fades to sage, nothing moves and the sheen is gone.

In 450 ms, out 300 ms, cubic-bezier(.4, 0, .2, 1). The label switches colour in the middle of the fade, so it is not grey on grey for long.

Desktop 1280: hover a button

Phone 390: no hover, press only

2. Curtain fill

The hover colour rises from the bottom edge and drops back down when the pointer leaves; the label changes colour as the edge passes through it.

In 550 ms, out 400 ms, cubic-bezier(.4, 0, .2, 1).

Desktop 1280: hover a button

Phone 390: no hover, press only

3. Wipe

The hover colour slides in from the left and leaves to the right, not back the way it came. Cost: while the edge crosses the label, part of the text has the wrong colour for a moment, and the fill changes side if the pointer leaves half-way.

In 550 ms, out 450 ms, ease-in-out-cubic.

Desktop 1280: hover a button

Phone 390: no hover, press only

4. Slow sheen

Today's idea, calmer: the slow crossfade of look 1 plus a wider, softer band of light that crosses once per hover and does not sweep back.

Colours in 450 ms, out 300 ms, cubic-bezier(.4, 0, .2, 1). Sheen 900 ms, ease-out-quad, fades out in 240 ms on leave.

Desktop 1280: hover a button

Phone 390: no hover, press only

5. Label roll

The label slides up and an identical copy rolls in from below while the colours fade as in look 1; the cart icon lifts 2 px. Cost: every button label needs a wrapper, so this is the only look that touches templates.

Roll in 500 ms, out 400 ms; colours in 450 ms, out 300 ms; cubic-bezier(.4, 0, .2, 1).

Phone 390: no hover, press only
