UX-14 Type scale

Three role-based scales on the same real storefront content (Adela cushion PDP, Homewares PLP, About CMS). Figtree only. Each option uses nine roles: display, h1, h2, h3, h4, body, copy, note, label. Title becomes an alias of display or h1 in Step 2. Page-named tokens (banner-title, noroute-lead, breadcrumbs, nav, title-section) are not new roles.

Answer with 1, 2 or 3. Phone frames are 390 wide; wide frames are 1280. Scroll inside a frame to see the ladder, then PDP, PLP and CMS set in that scale.

1. Cleaned familiar

Keeps today’s Elme sizes in spirit, but removes the h3=h4 and h5=body collisions, grows h1 at desktop (40px, not the unused 60), and lifts body/note line-heights to 1.5 / 1.4. Smallest change from the live site.

2. Clear modular

Even steps and a stronger desktop jump (display 64 / h1 48). Headings read as a ladder at a glance; body stays 16–17 with 1.55 line-height. Best if hierarchy on PLP banners and CMS should feel editorial.

3. Soft readable

Body steps up to 17px with 1.55 line-height; display stays calmer (32 / 48). Headings still distinct, but the page feels quieter and more long-form friendly. Pick this if CMS and PDP copy matter more than big category banners.
